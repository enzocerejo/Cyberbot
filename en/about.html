Behind Cyber

About me

Cyber is entirely vibe-coded: all of its code is written by an artificial intelligence. I, Enzo Cerejo, am simply the project lead: I decide what needs to be done.

An idea on a whim

Cyber was never planned. On 25 October 2026, I just wanted a bot of my own to try things out on a Discord server. The very first question was simple: "Can you help me make my own Discord bot?"

The idea grew fast. Most servers stack five or six bots: one for tickets, one for moderation, one for levels, one for giveaways… So I thought: why not one free bot that does it all? That became Cyber's goal.

Entirely vibe-coded

I don't code. Every line of Cyber (the bot, the dashboard and this website) is written by an AI, Claude. I explain what I want in plain words, it builds it, tests it and tells me what changed.

I'd rather say it clearly: it's a different way to build a project, and I have nothing to hide. Every step is described in the project documentation (in French), including the problems along the way.

My role: project lead

  • Deciding what to build: features, priorities, the look of the website and the bot.
  • Testing every new version on real Discord servers and reporting what's wrong.
  • Coordinating: the accounts (Discord, GitHub, domain name), going live and members' feedback.
  • Signing off on security and data choices before every update.

Vibe-coded, but closely watched

Code written by an AI needs to be checked. Cyber goes through regular security audits, asks for minimal permissions, never publishes a secret and keeps only the data it needs: anyone can see or delete theirs with /mydata.

The result: one week after it was born, Cyber was verified by Discord. The latest updates are in the changelog.

An idea, a question? Drop by the support server or leave some feedback: I read everything.
