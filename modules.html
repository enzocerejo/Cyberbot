Modules sur mesure

Une fonction qui n'existe dans aucun bot ? Elle est codée exprès pour ton serveur, puis ajoutée à Cyber en saisissant un simple identifiant, comme une cassette qu'on insère.

  1. 1

    Tu décris ton idée

    Sur le serveur de support, explique ce dont ton serveur a besoin : un mini-jeu, un système d'économie, une commande propre à ta communauté, un lien avec un autre service…

  2. 2

    Le module est codé pour toi

    On valide ensemble ce qu'il doit faire, puis il est développé et testé. Il respecte les mêmes règles que le reste de Cyber : pas de permission inutile et pas de donnée gardée sans raison.

  3. 3

    Tu reçois ton identifiant

    Un code unique, réservé à ton serveur, du type CYB-7F3A-K9QM-2XRT. Il ne fonctionne pas ailleurs.

  4. ✓

    Tu l'ajoutes en un clic

    Dans le tableau de bord, ouvre Modules publics (tout en haut du menu) puis le petit bouton « Code de module », colle ton identifiant : Cyber installe le module tout seul, sans redémarrage ni nouveau bot à inviter.

    MODULE · CYB-7F3A-K9QM-2XRT
    ▼ Code de module
Rien que pour ton serveur. Le code ne marche que sur le serveur pour lequel il a été créé, et un administrateur peut désinstaller le module à tout moment dans Modules publics (ou avec /modules). Pour commencer, décris ton idée ci-dessous.
